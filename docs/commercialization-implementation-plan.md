# Commercialization Implementation Plan

This document outlines the steps required to implement the Tickonomics commercialization roadmap, as defined in [ADR-034](docs/adr/ADR-034-licensing-strategy.md).

## Phase 1: Immediate Monetization (SaaS & Support)
- [ ] Define support tiers and service offerings.
- [ ] Draft `COMMERCIAL.md` to advertise these services.
- [ ] Implement hosting infrastructure for "Tickonomics Cloud" (Proprietary platform, separate from core).

## Phase 2: Preparing for Dual Licensing (CLA Setup)
- [ ] Create `CONTRIBUTING.md` in the root directory.
- [ ] Include explicit Contributor License Agreement (CLA) language in `CONTRIBUTING.md`.
- [ ] Formally announce the new contribution policy.

## Phase 3: Commercial License Launch (Future)
- [ ] Assess enterprise demand for a non-AGPL (commercial) license.
- [ ] Create commercial license terms.
- [ ] Begin licensing code under the new commercial license alongside the existing AGPL version.
